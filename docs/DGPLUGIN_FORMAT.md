# Формат `.dgplugin`

`.dgplugin` — обычный ZIP-архив с обязательным `manifest.json`.

Минимальная структура:

```text
example.dgplugin
├── manifest.json
└── main.py
```

Пример манифеста:

```json
{
  "id": "example.plugin",
  "name": "Example",
  "version": "1.0.0",
  "author": "Developer",
  "description": "Описание плагина",
  "main": "main.py",
  "min_devgram": 3
}
```

## Поля runtime

| Поле | Назначение |
| --- | --- |
| `id` | Постоянный идентификатор плагина. |
| `main` | Точка входа относительно корня архива; по умолчанию `main.py`. |
| `min_app_version` | Минимальная версия приложения DevGram. |
| `min_devgram` / `min_sdk` | Минимальный уровень API плагинов. |
| `requirements` | Список зависимостей, которые должны быть вложены в пакет. |

Поля каталога, локализации, ресурсов и сборки подробно описаны в
[официальной документации](https://docs.devgram.space/docs/builder).

## Проверки при установке

Runtime проверяет, что:

- архив является корректным ZIP и содержит не более 4096 записей;
- нет повторяющихся имён, абсолютных путей и выхода через `..`;
- существует `manifest.json` и указанная точка входа;
- `id` содержит только буквы, цифры, `.`, `_`, `-` и не длиннее 64 символов;
- требования имеют допустимый формат и присутствуют внутри пакета;
- текущая версия приложения и уровень API соответствуют манифесту.

Для создания и проверки пакета используется
[DevGram Builder](https://github.com/firedragoq/DevGramBuilder).
